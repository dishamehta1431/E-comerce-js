# 👗 The Style Hub – E-Commerce Website

The Style Hub is a fashion e-commerce website developed using HTML, CSS, JavaScript, and Bootstrap 5. It allows users to browse fashion products, filter categories, manage their shopping cart, and perform product management operations.

## ✨ Features

- 🛍️ Display fashion products with images, names, and prices.
- 👕 Filter products by All, Men, Women, and Accessories.
- 🛒 Add products to the shopping cart.
- ➕ Increase and decrease product quantities.
- 🗑️ Remove products from the cart.
- 💰 Calculate product totals and grand total.
- 💳 Checkout with an order confirmation message.
- ➕ Add new products using a product name, image URL, and price.
- ✏️ Update existing product details.
- ❌ Delete products from the product list.
- 💾 Save cart items using browser LocalStorage.
- 📱 Responsive design using Bootstrap.
- ℹ️ About Us section introducing The Style Hub.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files are in the correct folder.
4. Open `index.html` in your browser.
5. You can also use the Live Server extension in VS Code.

**Note:** An internet connection is required to load Bootstrap and external product images.

## 🛒 How to Use

1. Open the website to view available products.
2. Select Men, Women, or Accessories to filter products.
3. Click **Add to Cart** to add products to your cart.
4. Open the Cart section to manage quantities and remove items.
5. Click **Check Out** to display the order confirmation.
6. Click **Add Product** to add a new product.
7. Click **Update** to edit product details.
8. Click **Delete** to remove a product.
9. Visit the About Us section to learn about the brand.

## 💾 Data Storage

The shopping cart is stored in browser LocalStorage, allowing cart items to remain after refreshing the page in the same browser.

Product details are stored in a JavaScript array. Therefore, added, updated, or deleted products are not permanently saved after a page refresh.

## ⚠️ Limitations

- The project does not use a backend or database.
- Checkout does not process real payments.
- Product changes are not permanently stored.
- Product search functionality needs to be implemented in JavaScript.
